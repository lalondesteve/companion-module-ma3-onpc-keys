## grandMA3 onPC Keys

Press grandMA3 console hardware keys, special executors, and numbered executors (`101`–`490`) in grandMA3 onPC without needing window focus.

### Setup

1. Leave **Transport** on **OSC first, grandMA3 Terminal fallback** (or choose **grandMA3 Terminal only** / **OSC only**).
2. Set **grandMA3 user** to the user logged in on onPC (used for its `KeyboardShortCuts` profile) and **Display number** to the target onPC display (usually `1`).
3. For OSC, open **Menu → In & Out → OSC** in onPC, configure a line on the matching port with **Receive Command** enabled, select the network interface (e.g. `127.0.0.1`), and turn on **Enable Input**.

### Presets

Presets press on button down and release on button up for console-like behavior (including holding **MA** while pressing another key, or holding **Flash** / **Temp** executors).
